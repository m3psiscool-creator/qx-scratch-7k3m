Provide the Epic login

This card only appears when the login is needed or the test fails. Your Epic account must be signed in on epicgames.com in this browser.

  1. Open the Epic authorization page. It shows a short block of text containing an authorizationCode.
  2. Copy the code (the long string only) and paste it here.
  3. After saving, press Make login permanent once, so no more codes are needed.
